## ✅ Final Version (Use This)

**GarageGo – Roadside Vehicle Breakdown Assistance Platform | [code] | [demo]**

- Developed a full-stack, real-time roadside assistance platform connecting stranded vehicle owners with nearby mechanics across 12+ cities using GPS-based matching, Haversine distance ranking, and ETA-aware request routing.
- Implemented role-based authentication and profile management for customers and mechanics using Firebase Authentication (Email/Password and Google OAuth) and Cloud Firestore, secured with role- and owner-based Firestore security rules.
- Built a scalable push notification system using Firebase Cloud Messaging (FCM) and a Node.js/Express.js REST API protected by Firebase ID token verification, with multi-device FCM token management and automated invalid-token cleanup.
- Engineered a fault-tolerant dispatch system using Firestore transactions and a mechanic routing queue with Twilio voice-call fallback, automatically reassigning rejected or unanswered requests to the next nearest mechanic within 60 seconds.
- Designed an OTP-based service completion workflow with real-time request tracking using Firestore real-time listeners and Leaflet maps, covering the complete lifecycle from breakdown request to verified job completion.
- **Tech Stack:** React.js, Node.js, Express.js, Firebase (Authentication, Cloud Firestore, Cloud Messaging, Hosting), Twilio API, Leaflet.js, Tailwind CSS, REST APIs, Geolocation API, Vite
